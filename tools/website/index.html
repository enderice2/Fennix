About

Fennix is an operating system written from scratch: its own kernel, its own drivers, its own userland. It does not derive from Linux, BSD, or any other existing system.

  • Custom kernel with its own scheduler and memory manager
  • Minimal userland and shell

The project is still in early developement.

Source code

The source is kept in a git repository. Browse it at github.com/enderice2/Fennix or clone it with: 

$ git clone https://github.com/enderice2/Fennix.git

Fennix is released under the GPL-3.0 license.

Building from source

$ git clone https://github.com/enderice2/Fennix.git
$ cd Fennix
$ make setup
$ make run
